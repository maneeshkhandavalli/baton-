# Loopsii reference breakdown (round 2) and the Baton mapping

**Inspected:** loopsii.com in Chrome (Claude in Chrome extension), 19 Nov 2026. The desktop window is 2560 CSS px
wide; 1440, 1024, 768 and 390 were viewed through a local header-stripping proxy that frames the page in a fixed-width
iframe (scratchpad only; nothing from Loopsii is committed). Computed styles, section geometry and the script bundle
were read with `javascript_tool`. Numbers below are CSS px at a 1440 × 900 viewport unless marked.

## System

| Trait | Reference | Baton |
|---|---|---|
| Sizing unit | everything is a multiple of `container / 1920` (container = `clamp(1200px, 100vw, 2560px)`), so the page scales with the viewport; separate ideal widths for tablet (768) and phone (375); breakpoints 479 / 767 / 1023 | same three-basis unit (`--u` in `landing.css`), with px floors on body text so it never drops below legible sizes |
| Type | one grotesk (Saans, weight 400) for display and body, Caveat for handwritten labels (`--hand-scale: 1.5`), Geist Mono for tiny uppercase corner labels | Host Grotesk 500 (display and large text), Atkinson Hyperlegible Next (small body), Caveat (hand), Atkinson Hyperlegible Mono (corner labels) |
| Scale (1440) | display 75 / lh 1 / −0.03em; section h2 55.5 / lh 1 / −0.02em; statement 40.5 / lh 1.1; card h3 25.5 / lh 1.1; lede 21 / lh 1.4 / −0.03em; nav 12 | display 100u, h2 74u, statement 54u, h3 34u, lede 28u (the same multiples) |
| Colour | paper `#f0f0f0`, ink black; flat pastel tiles (sky, sage, coral, lime, apricot, steel); one dark band; one lime band; sky-blue dithered footer field | paper `#f6f6f4`; pastel tiles derived from Baton's evidence colours (sky = sourced, apricot = inferred, mauve = conflicting, stone = missing) plus Baton's highlighter lime; dark band in Baton ink |
| Surfaces | radii 45 (cards), 30 (split panels), pill nav and buttons; hairline blueprint frames with 6 px square corner ticks and mono corner labels; faint graph paper | same |
| Motion stack | Lenis + GSAP 3 with ScrollTrigger (bundled), scrubbed timelines, one pinned section, CSS `position: sticky` stacks; eases `cubic-bezier(.84,0,.16,1)` (.8 s / .6 s), `cubic-bezier(.76,0,.24,1)`, spring `cubic-bezier(.3,1.3,.4,1)` (.45 s), accordion `grid-template-rows .6s cubic-bezier(.65,0,.35,1)`, icon `rotate .6s`; GSAP eases power2/3.out, back(1.2), expo; `(hover: hover)` gates hovers | Lenis (existing) + `gsap@3.13.0` ScrollTrigger, the same curves and durations; all motion inside `gsap.matchMedia("(prefers-reduced-motion: no-preference)")` |
