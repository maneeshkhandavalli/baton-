Meera Iyer), phone numbers in the `99999 000NN` pattern and `example.org` emails. No real personal data.

The files are generated by `build.ts` (single source of truth) and committed so QA can upload them in
the browser. `lib/parsers/__tests__/demo-multiformat-r3.test.ts` fails if a committed file differs from
the build or from the outcomes below. Regenerate from the repository root with:

```bash
node --import ./lib/contracts/__tests__/resolve-ts.mjs fixtures/demo/round3-multiformat/build.ts
```

Each file has a distinct SHA-256, so the whole set can go into one draft (7 of the 10-source limit)

## Note for QA (B2): how the fake adapter yields `contradicts`

QA owns the conflict fixture (tests/fixtures/**); this is how to make one that works under the
deterministic fake adapter (`lib/ai/providers/fake.ts`, read-only here). Verified against the current code.

1. **Extraction** quotes one verbatim sentence per candidate. The category is the FIRST matching keyword
   rule in this order: decision (`decided|agreed|we will go with|finalised`), owner (`in charge of|
   responsible for|handles|owns`), blocker, risk, recurring_problem, next_action, open_task. A sentence
   must be on one line (bodies are split on `\n`), ≥ 12 characters and ≥ 3 words.
2. **Attachment** (`lib/pipeline/dedup.ts`): a later candidate attaches to an existing point only when, in
   the same category and access level, its normalised statement is equal, OR its subject key is equal.
   The subject key for `owner` is `attributes.responsibility`, which the fake extractor sets to the
   sentence truncated to **200 characters**. Identical sentences never contradict, so the working path is:
   two `owner` sentences (no decision keyword in them) that share the same first 200+ characters and differ
   only after that.
3. **Verification** (`defaultVerify`): `contradicts` when word overlap between the point's statement and the
   attached quote is ≥ 30 % AND exactly one of them matches the negation pattern
   `not|never|no longer|cancel(l)ed|won't|isn't|doesn't` (ASCII apostrophe only). Otherwise ≥ 60 % →
   `supports`, ≥ 30 % → `partial`.
4. A point with one active, verified `contradicts` link becomes `conflicting` (recompute in
   `20261111000400_lifecycle.sql`), even though its own first quote `supports` it.

Working pair (one source each, both `everyone` access; probe result: owner/owner, attached, 94 % overlap →
`contradicts`; the first source's own quote → `supports`):

```
Source A (chat line body):
Arjun Pillai is responsible for booking the main auditorium, collecting the hall deposit from the finance office, confirming the projector and the sound check with the AV team, and sending the final rehearsal schedule to every volunteer for the spring production.

Source B (one Markdown paragraph on ONE line):
Arjun Pillai is responsible for booking the main auditorium, collecting the hall deposit from the finance office, confirming the projector and the sound check with the AV team, and sending the final rehearsal schedule to every volunteer, but that is no longer the case after the committee meeting.
```

Pitfalls: a full stop inside the shared prefix splits the sentence; any decision keyword in it changes
the category; a phone/email in the prefix is masked identically in both (fine) but must be the same
value; different access levels never merge; the order of sources does not matter (the negation only has
to differ). This depends on the fake adapter's current heuristics (Agent 4 owns them; a PI-11 change to
`defaultVerify` or the 200-character truncation would need this note updated).
